# AssetDrive desktop

Installers for the AssetDrive desktop app on Windows and Mac.

**Download:** open [Releases](https://github.com/Handovo/assetdrive-desktop/releases/latest) and pick:

- **Windows:** `AssetDrive Setup <version>.exe`
- **Mac:** the `.dmg` for your Mac (`arm64` for Apple silicon, `x64` for Intel)

Once installed, the app updates itself from this page.

This repository holds release files only. There is no source code here.
